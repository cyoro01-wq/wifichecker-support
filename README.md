# WiFiチェッカー サポート

Mac のメニューバーで Wi-Fi の通信速度・電波強度・安全性を確認できる macOS アプリ「WiFiチェッカー」の紹介・サポートサイトです。

- 紹介ページ: https://cyoro01-wq.github.io/wifichecker-support/
- サポート・よくある質問: https://cyoro01-wq.github.io/wifichecker-support/support.html
- プライバシーポリシー: https://cyoro01-wq.github.io/wifichecker-support/privacy.html
- Mac App Store: https://apps.apple.com/jp/app/id6797778849

## お問い合わせ

不具合のご報告やご質問は [Issues](https://github.com/cyoro01-wq/wifichecker-support/issues) からお寄せください。
Issues は公開の場です。Wi-Fi の名前（SSID）、パスワード、IP アドレスなどの個人情報は書き込まないでください。
