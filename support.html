よくある質問

「SSIDを取得できません」と表示され、Wi-Fiの名前が出ません。

macOS では Wi-Fi の名前（SSID）を読み取るアプリに位置情報の許可が必要です。システム設定 → プライバシーとセキュリティ → 位置情報サービス を開き、位置情報サービスと「WiFiチェッカー」をオンにしてください。許可するとアプリの表示は自動で更新されます。

位置情報は何に使われますか？

macOS の仕様で、Wi-Fi の名前の取得と周辺Wi-Fiのスキャンに位置情報の許可が必要なためです。WiFiチェッカーは位置そのものを取得・保存・送信しません。許可しなくても通信速度の表示は使えます。

メニューバーに速度が表示されません。

メニューバーの項目が多いと、画面の幅やカメラのノッチに隠れて表示されないことがあります。ほかのメニューバーアプリを減らすか、WiFiチェッカーの設定で「メニューバーにネットワーク名を表示」をオフにして表示を短くしてください。アプリを Finder や Launchpad から開くとメインウインドウが表示されるので、そこからも同じ情報を確認できます。

メニューバーの速度と回線速度テストの数値が違います。

メニューバーの速度は、いまMacで実際に流れている通信量を毎秒観測した値です。回線速度テストは計測サーバーと実際にデータを送受信して、回線の最大速度を測ります。通信していないときはメニューバーの値は小さくなるため、両者が違うのは正常です。

回線速度テストが失敗します。

インターネットに接続しているか確認してください。回線速度テストは Cloudflare の計測サーバー（speed.cloudflare.com）と通信します。VPN、会社や学校のネットワーク、セキュリティソフトのフィルタで遮断されている場合は測定できません。電波の安定した場所でもう一度お試しください。

セキュリティ診断で「危険」や「注意」と表示されました。

同じ名前で暗号化あり・なしのアクセスポイントが混在している、保存済みのWi-Fiと紛らわしい名前のWi-Fiがある、暗号化されていない・旧式の暗号化を使っている、といった兆候を知らせています。心当たりのないWi-Fiには接続せず、重要な通信は暗号化されたWi-FiやVPNで行ってください。電波情報だけを使った簡易診断のため、安全を保証するものではありません。

アプリから別のWi-Fiに切り替えられません。

Mac App Store 版は macOS のセキュリティ上の制限（App Sandbox）により、アプリから接続先を切り替えることができません。一覧でWi-Fiを選ぶと案内が表示されるので、「ネットワーク設定を開く」から macOS のWi-Fi設定で接続してください。

Macの起動時に自動で起動させたい（止めたい）。

WiFiチェッカーのメニューで「Mac起動時に自動で起動」をオン／オフしてください。システム設定 → 一般 → ログイン項目 からも変更できます。

アプリを終了するには？

メニューバーのWiFiチェッカーをクリックし、いちばん下の「終了」を選ぶか、メニューを開いた状態で Command + Q を押してください。ウインドウを閉じただけではメニューバーの表示は残ります。

対応している macOS は？

macOS 13 Ventura 以降に対応しています。

お問い合わせ

不具合のご報告やご質問は、GitHub の Issues からお寄せください。

お問い合わせ（GitHub Issues）

  • お使いの macOS のバージョンと WiFiチェッカーのバージョンを書き添えていただくと、調査がスムーズです。
  • Issues は誰でも閲覧できる公開の場です。Wi-Fiの名前（SSID）、パスワード、IPアドレス、メールアドレスなどの個人情報は書き込まないでください。
